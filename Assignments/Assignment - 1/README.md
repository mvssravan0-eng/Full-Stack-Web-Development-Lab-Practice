# Assignment 1: JavaScript Inheritance Types

This folder contains implementations of different inheritance patterns in JavaScript.

## Files Structure

* **`Src/`**: Contains execution files.
  * [`single.js`](file:///d:/Full%20Stack%20Web%20Development%20Lab%20Practice/Assignments/Assignment%20-%201/Src/single.js): Single inheritance.
  * [`multilevel.js`](file:///d:/Full%20Stack%20Web%20Development%20Lab%20Practice/Assignments/Assignment%20-%201/Src/multilevel.js): Multilevel inheritance.
  * [`hierarchical.js`](file:///d:/Full%20Stack%20Web%20Development%20Lab%20Practice/Assignments/Assignment%20-%201/Src/hierarchical.js): Hierarchical inheritance.
  * [`multiple.js`](file:///d:/Full%20Stack%20Web%20Development%20Lab%20Practice/Assignments/Assignment%20-%201/Src/multiple.js): Multiple inheritance using mixins.
  * [`hybrid.js`](file:///d:/Full%20Stack%20Web%20Development%20Lab%20Practice/Assignments/Assignment%20-%201/Src/hybrid.js): Hybrid inheritance.
  * [`prototypal.js`](file:///d:/Full%20Stack%20Web%20Development%20Lab%20Practice/Assignments/Assignment%20-%201/Src/prototypal.js): Prototypal inheritance using `Object.create()`.

## How to Run

Navigate to the `Src` directory and execute using Node:
```bash
node single.js
node multilevel.js
node hierarchical.js
node multiple.js
node hybrid.js
node prototypal.js
```
