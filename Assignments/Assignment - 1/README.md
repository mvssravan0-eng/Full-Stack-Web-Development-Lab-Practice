# Assignment 1: Implement Inheritance Types using JavaScript

This assignment demonstrates the different types of inheritance possible in JavaScript.

## Types of Inheritance Covered:
1. **Single Inheritance**: One subclass inheriting from a single superclass (using ES6 \class\ and \extends\).
2. **Multilevel Inheritance**: A derived class inheriting from another derived class.
3. **Hierarchical Inheritance**: Multiple derived classes inheriting from the same base class.
4. **Prototypal Inheritance**: The native JS inheritance model using \Object.create()\.
5. **Multiple Inheritance (Mixins)**: Since JavaScript does not support multiple inheritance with classes, we use the Mixin pattern (\Object.assign\) to copy methods from multiple objects into a single class prototype.
