# Experiment 6: Mini Course Manager (Express & Node.js)

This folder contains a mini full-stack application built using Node.js and the Express framework.

## How to Access and Run the Application

1. **Open your terminal or command prompt** and navigate to the \Src\ folder inside this experiment:
   \\\ash
   cd Src
   \\\

2. **Install dependencies** (if not already installed):
   \\\ash
   npm install
   \\\

3. **Start the Express server**:
   \\\ash
   node server.js
   \\\
   You should see a message in the terminal saying: \Server is running on http://localhost:3000\

4. **Access the application**:
   Open your preferred web browser (Google Chrome, Edge, etc.) and navigate to:
   http://localhost:3000

## Application Features
- **Frontend**: Built with HTML, CSS, and Vanilla JavaScript (Fetch API).
- **Backend**: Built with Node.js and Express. Provides a REST API (\/api/courses\) to handle GET, POST, and DELETE requests.
- **Functionality**: You can view a list of courses, add new courses, and delete existing ones.
