Understanding the Document Object Model (DOM)

What is the DOM? The Document Object Model is a programming interface for web documents. It represents the HTML page as a tree of objects (nodes), enabling scripting languages like JavaScript to programmatically access, modify, delete, and add element contents, inline CSS styles, and tag attributes.
